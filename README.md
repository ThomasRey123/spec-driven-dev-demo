# Spec Driven Development Demo

Demo-Repository für spezifikationsgetriebene Softwareentwicklung.

Der Entwicklungsablauf beginnt mit einer Spezifikation: Anforderungen und
Akzeptanzkriterien beschreiben das gewünschte Verhalten und bilden die Grundlage
für Implementierung und Tests.

Dieses Repository enthält zunächst die Projektbeschreibung. Installations-,
Start- und Testanweisungen folgen mit der ersten Implementierung.
